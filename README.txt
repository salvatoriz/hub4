# Nocteris

Site em HTML, CSS e JavaScript puro.

- Apostilas: abre diretamente https://nocteriss-apostilas.vercel.app/
- Scripts: 10 plataformas, com acesso ao Discord oficial.
- Equipe: Shuziro Astral, Dr3m e servidor Nocteris.
- Contador de progresso de 2026 em tempo real.
- Sem contador de FPS na tela.
- Responsivo para PC e celular.

Abra `index.html` no navegador.


Atualização v3: OpenFuture, Shuziro Astral, Autoquest/Ghosthub e módulo de apoio/doação adicionados.

Atualização v6: card externo corrigido para Scripts, módulo Zunder adicionado e utilitário Copia e colar com botão de cópia.
